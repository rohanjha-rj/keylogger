About

What does it do?

This script silently monitors keyboard events in the background using the pynput library's OS-level hooks. Every keystroke is captured, classified, and written to a local log file.

Regular characters are logged as-is. Special keys like Space and Enter are translated into readable output. Modifier keys (Shift, Ctrl, Alt) are filtered out. Non-printable keys are tagged in bracket notation like [BACKSPACE] or [F5].

The result is a clean, human-readable transcript of everything typed — with minimal disk overhead thanks to buffered I/O.

Workflow

How it works

Four stages from keypress to log file.

Listen

Capture

keyboard.Listener spawns a background thread that hooks into the OS keyboard event stream. Every physical key press fires the callback.

Classify

Filter & Map

Each key is classified: modifiers are ignored, special keys are mapped to readable strings, and printable characters use their .char attribute.

Buffer

Accumulate

Keystrokes accumulate in an in-memory list. Once 10 characters are buffered, they're flushed to disk in a single write — reducing I/O overhead.

Log

Write to File

Buffered content is appended to log.txt with UTF-8 encoding. The buffer is also flushed on graceful exit via Escape or Ctrl+C.

Features

Built with care

Clean, robust, and efficient by design.

⚡

Buffered I/O

Keystrokes are batched in memory and flushed every 10 characters, dramatically reducing disk writes compared to per-keystroke file access.

🔤

Smart Key Handling

Uses pynput enums and the key.char attribute instead of brittle string parsing. Unmapped keys are tagged in [BRACKET] notation.

🛑

Graceful Exit

Press Escape to stop cleanly — the remaining buffer is flushed before shutdown. Ctrl+C is also handled with a guaranteed final flush.

🛡️

Error Safety

A try/except wraps the callback to prevent silent listener-thread crashes. The main block uses try/finally for guaranteed cleanup.

Setup

Get started

Clone, install, run — three steps.

1 — Clone & Setup 
# Clone the repository
$ git clone https://github.com/rohanjha-rj/keylogger.git
$ cd keylogger

# Create virtual environment
$ python -m venv .venv
$ .venv\Scripts\activate
2 — Install dependencies 
$ pip install -r requirements.txt
3 — Run 
$ python keylogger.py
# Press Escape to stop recording

Key behavior

How each key type is handled by the logger.

Key Pressed Logged As Note
a, Z, 5, @ the character itself via key.char attribute
Space " " space character
Enter \n newline
Tab \t tab character
Backspace [BACKSPACE] bracket notation
Delete, Home, F5… [DELETE], [HOME], [F5] bracket notation for all unmapped specials
Shift, Ctrl, Alt, Cmd — silently ignored
Escape — stops the program
